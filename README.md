# atividade-de-redes-de-computadores
Programa em Python desenvolvido para uma atividade de Redes de Computadores, com ferramentas para análise e diagnóstico de rede.
Este projeto foi desenvolvido como parte de uma atividade da disciplina de Redes de Computadores.

O objetivo do programa, desenvolvido em Python, é apresentar e analisar algumas informações relacionadas à configuração e ao funcionamento da rede do computador.

Funcionalidades

O programa é capaz de:

Exibir o endereço IP do computador;
Identificar o Gateway padrão da rede;
Exibir os servidores DNS configurados;
Executar o comando Traceroute/Tracert, permitindo visualizar o caminho percorrido pelos dados até um determinado destino;
Realizar testes relacionados ao Jitter, analisando a variação no tempo de resposta da conexão;
Executar consultas utilizando o NSLookup, permitindo obter informações sobre domínios e servidores DNS.
Tecnologias utilizadas
Python
Conceitos e ferramentas de Redes de Computadores

Este projeto tem como objetivo colocar em prática conhecimentos relacionados à configuração de redes, resolução de nomes, diagnóstico de conexão e análise da comunicação entre dispositivos em uma rede.
